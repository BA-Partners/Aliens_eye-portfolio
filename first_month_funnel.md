# First-Month Order Funnel

## Stage mapping
1. Profile view
2. Gig impression
3. Click
4. Inquiry / message
5. Order placed
6. Delivery accepted

## Assumed baseline metrics (personal brand)
- Profile views/day: 180-260
- Impressions/day: 2,200-3,800
- Click-through rate: 0.6%-1.1%
- Inbound message rate: 3.1%-4.7%
- Conversion inquiry -> order: 18-26%
- Delivery acceptance: 86-92%

## Conversion levers to optimize
- reply buyer requests within 30 minutes
- always share 1 short proof artifact/screenshot
- publish 1 deliverable log per completed order
- rotate 3 gig thumbnails every two weeks
- send refund-quality follow-up message asking for testimonial

## Daily actions (30 min/day recommended)
- 5 buyer request replies
- 1 Twitter post or comment
- 1 group post or DM follow-up
- 1 outreach email
- 15 minutes on delivery quality + skill reuse

- Type A scoped scripts x4 => $320-$880 if priced $80-$220
- 1 Type B hourly engagement => $40-$90/hr x4h => $160-$360
- blended first month potential: $480-$1,240
- realistic conservative target: $300-$600 with 4 small orders
